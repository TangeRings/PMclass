Create a browser-based Memory Matching Game.

Game rules:

* Display a grid of cards face down (for example, 4×4 grid with 8 pairs).
* Each card has a hidden symbol or image.
* When the user clicks a card, it flips face up.
* The user can flip exactly 2 cards per turn.
* If the two cards match, they remain face up permanently.
* If they do not match, they flip back face down after a short delay (e.g., 1 second).
* Prevent clicking additional cards while two cards are being compared.

Game features:

* Shuffle cards randomly at the start of the game.
* Track number of moves.
* Track time elapsed.
* Display a win message when all pairs are matched.
* Include a restart button.

UI requirements:

* Smooth card flip animation.
* Clean, modern design.
* Responsive layout (works on desktop and mobile).
* Cards should visually flip using animation (CSS transform or equivalent).

Optional enhancements:

* Sound effects for match / mismatch
* Difficulty levels (4×4, 6×6, 8×8)
* Score system based on moves and time
